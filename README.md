A single line — the museum label a museum in the year 3000 places next to an ordinary object from today. At most 200 characters.

> Exhibit 47: the plastic fork. Before humans learned to eat with their hands like civilized people, they used this.

## Run

```sh
node main.ts
```

Reads the entry from `entry.txt` and writes it to `output.txt` in the directory given by `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` (defaults to `output/`).
